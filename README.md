# Super Atomic Box

A Super Caixa Atômica: da matéria que se vê ao átomo. A primeira caixa da Caixa Química
(caixaquimica.com.br), com o gato Bohr.

- Sem dependências e sem etapa de build: abra com `python3 -m http.server` e vá a http://localhost:8000.
- Testes: `node testes/rodar.js`.
- Plano de conteúdo e visual: `docs/plano-atomic-box.md`.
